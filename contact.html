Contact

Object Random Generator is run by one person, so email is the only channel — there is no support desk and no phone number. Every message is read, usually within two or three working days.

Before you write

Reporting a bug. Tell us which browser and device you were on, what you set (how many objects, which categories, which difficulty) and what happened instead of what you expected. If a draw looked wrong, mention the link you copied — the filters are in the address, so it lets us reproduce the exact setup.

Suggesting an object. Say which of the ten categories it belongs in and whether you would call it easy, medium or hard to draw. Suggestions that are concrete, everyday objects stand the best chance of being added.

Anything else. Corrections to the page text, questions about the privacy policy, and advertising or permission requests all go to the same address.

What this address is not for

The site is a free generator, not a homework service, so we cannot draw objects for you or check finished drawings. We also cannot license the list for a textbook or an app — the object names are ordinary English nouns and free to use, but the page text is not.
