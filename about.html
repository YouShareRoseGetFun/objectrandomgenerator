About Object Random Generator

What this site is

Object Random Generator is a free tool that draws everyday objects at random. You choose how many you want, which of ten categories to draw from, and whether you want objects that are easy, medium or hard to draw; then one button gives you a list you can copy or send. It needs no account, no download and no installation, and it works the same on a phone as on a laptop.

Why it was built

Random object generators are not new, and most of them share the same three problems: they return one object at a time, they have no categories, and they cannot tell you whether the object you just got is something you can actually draw in five minutes. This site was built around those three gaps. Drawing difficulty is a real filter here rather than an afterthought, the draw can return up to fifty objects at once, and the address of a draw can be copied so a teacher or a streamer can hand the exact same setup to somebody else.

How the object list was built

The list holds more than 120 everyday objects in ten categories: home and kitchen, food and drink, animals, nature, vehicles, tools, clothes, school, toys, and odds and ends. The shortlist was drafted and then reviewed entry by entry by hand. Three kinds of words were removed on purpose: abstract nouns such as "time" or "happiness", which cannot be drawn or acted out; objects most people have never held, which make a game stall; and anything unsuitable for a classroom, because a large share of this site's visitors are teachers and children. Each remaining object was then tagged easy, medium or hard by how hard it is to sketch, which is why a table is easy and a blender is not.

What the generator actually does

Every object in the list is a fixed entry in a static file. Pressing Generate shuffles that whole list on your device and takes the first items from the top, so the results are unpredictable but never invented: what you get back is a real, recognisable object that exists in the list. Nothing is written by a language model at the moment you click, which is also why the same filters can produce the same kind of result twice and why the site works offline once the page has loaded. Turning on Unique removes objects you have already drawn, so a long session does not repeat itself.

How the site is run

This is an independent, one-person project, not a company product. The site is a set of static pages, which keeps it fast and keeps running costs near zero; it is paid for by advertising, and there is no paid tier, no account system and no data collection beyond what the hosting provider logs. The full detail is on the privacy page.

Corrections

If an object is missing from the list, filed in the wrong category, or tagged with a difficulty you disagree with, write to the address on the contact page. Suggestions are read and the list is updated when they are right.
