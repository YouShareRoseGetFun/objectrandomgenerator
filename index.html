    What is this object random generator?

    This is a free random object generator: a list of more than 120 everyday objects, grouped into ten categories and tagged by how hard each one is to draw. Every draw shuffles the whole list and takes the first few items, so the results are unpredictable but never made up on the fly — you always get a real, recognisable object back.

    Nobody needs an account or an app. Open the page, press one button, and the objects appear. If you want a draw you can send to someone else, press Copy link to this draw and the URL keeps your filters, so the same setup opens on their screen too.

    How to use the object random generator

    1. Set how many objects you want — anywhere from 1 to 50. Five is a good default for a warm-up round.
    2. Narrow the categories. Untick everything except Food & Drink if you are playing a kitchen game, or leave only Animals for a classroom quiz.
    3. Pick a difficulty. Choose Easy to draw when children are sketching under a timer, or all three when you just need ideas.
    4. Press Generate. Tick Unique and every click removes the objects you have already seen, so a session never repeats. Tick it off again to reset.

    What people use a random object generator for

    Drawing prompts. The hardest part of a sketchbook session is deciding what to draw. Draw three objects, set a ten-minute timer and sketch all three — that is a full study session with no scrolling for ideas. With the Easy filter on, the prompts stay drawable for beginners and children.

    Classroom games. Teachers use the generator for guessing games, spelling rounds and storytelling warm-ups. Draw one object per student and ask for a sentence about it, or draw four and ask for a story that links all four. The category filter keeps the vocabulary at the right level for the class.

    Live streams and videos. Streamers draw a list of objects on screen and then have to find, build or draw them. Copying the draw link lets the idea be repeated on a second stream, and viewers can open the exact same filters at home.

    Writing and improv. Two unrelated objects is the fastest way out of a blank page. A kettle and a crown in the same scene already suggests a story; three random objects give an improv group its opening premise.

    Word games and party games. Charades, Pictionary and twenty-questions all need a steady stream of nouns. Generate 20 objects once, keep the list on your phone, and the game runs without anybody thinking of examples.

    Categories, difficulty and repeat draws

    Two filters do most of the work. Category controls the vocabulary: everything is an everyday object that a native speaker would recognise instantly, but the ten groups let you aim at food, animals, tools or anything in between. Difficulty is about drawing, not about the word — a table is easy, a blender is not, and a trampoline sits somewhere in the middle.

    The Unique toggle is what makes long sessions work. Without it, every draw is independent and short lists repeat. With it on, each object is removed after it appears, which is exactly what a game round needs. When the selection runs out, the generator says so and suggests widening the filters instead of silently repeating.

    Questions about the object random generator

    Is the object random generator free?

    Yes. The generator is free to use and needs no sign-up, no download and no account. Just pick your filters and press Generate.

    Can I generate more than one object at a time?

    Yes. Set the number anywhere from 1 to 50 and the generator returns that many objects in one click. This is how most teachers and streamers use it, so nobody has to wait for a second draw.

    Can I pick only food or only animals?

    Yes. Untick the categories you do not want and the generator only draws from the ones left on. You can also filter by drawing difficulty, which helps when the objects are for a sketchbook rather than a word game.

    Are the results really random?

    They are. Every click shuffles the full list and takes the first objects, so each draw is independent of the last one. Turning on Unique removes the objects you already drew so a session never repeats itself.

    Can I get objects that are easy to draw?

    Yes. Every object is tagged easy, medium or hard, and you can limit the draw to easy ones when you are drawing with children or under time pressure.
